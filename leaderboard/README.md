# Community leaderboard

**Development preview: current scores must not be used as an official ranking. No results have been published in this release.** Historical internal experiments are not included.

Submit a **Benchmark submission** GitHub issue with the information in [the submission contract](../docs/SUBMISSION.md). This release supplies an issue template, not an active hosted evaluation service.

Use separate tables for:

1. Open-data results: 15 tasks.
2. Direct UKB results: 17 tasks, with authorized access conditions disclosed.
3. Mixed-source (6) and repository-statistics (2) results, each labeled separately.
4. Boundary/protocol cases, reported separately from numerical reproduction results.

Self-reported results remain labeled **self-reported**. Only maintainers may mark a result **verified** after checking its commit, task coverage, provenance, artifacts and reproduction procedure. A high local score alone is insufficient.

Do not merge different task subsets, scoring protocols or target-access conditions into a single ranking.

All current scores are development-only and have no ranking score. “Verified execution” must not be relabeled “verified full-paper reproduction” without a frozen method and source contract.
