# Data Bundle: Oncology_003

This directory is a redacted scaffold for the ClinicalRepBench task `Oncology_003`.

The runnable governed benchmark should mount or generate the following resources at execution time:

- `analysis_dataset` or equivalent table bundle for the source-study cohort
- variable dictionary for exposures, outcomes, covariates, and censoring dates
- source-study-specific target metric file after adjudication
- provenance manifest describing public, licensed, or controlled-access origins

No real patient-level records or copyrighted source tables are redistributed in this scaffold.
