# Related Work: Oncology_001

This folder should contain redistributable citations, abstracts, variable dictionaries, and implementation notes for the source-study family.

For the public scaffold, only high-level task framing is provided:

- Domain: Oncology and cancer genomics
- Task: Pretreatment predictors of immune-checkpoint inhibitor response
- Endpoint: objective response and progression-free survival
- Re-Discovery: Recover the reported association between composite immune markers and response.
- New-Discovery: Identify whether toxicity-risk markers predict discontinuation independently of response.
