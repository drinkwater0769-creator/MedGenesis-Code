# Submissions for Respiratory_003

A valid submission should include:

- `submission.json`
- `report/report.md`
- `artifacts/primary_metrics.json`
- `artifacts/tables/table1.csv`
- `artifacts/tables/table2.csv`
- `artifacts/figures/figure1.svg`

`artifacts/primary_metrics.json` should report the six ClinicalRepBench dimensions and the Re-Discovery/New-Discovery scores using the metric IDs in `target_study/target_metrics.json`.
