# Submission contract

Each task submission contains:

```text
submission.json
code/analysis.py
report/report.md
artifacts/primary_metrics.json
artifacts/tables/table1.csv
artifacts/tables/table2.csv
artifacts/figures/figure1.svg
```

Example manifest (paths are relative to the submission root):

```json
{
  "submission_version": "0.1",
  "task_id": "Endocrinology_001",
  "report_path": "report/report.md",
  "metrics_path": "artifacts/primary_metrics.json",
  "artifacts": {
    "table1": "artifacts/tables/table1.csv",
    "table2": "artifacts/tables/table2.csv",
    "figure1": "artifacts/figures/figure1.svg"
  }
}
```

Metrics use `{"metrics": {"metric_id": 1.23}}`, with measured values and task-defined identifiers. The number here illustrates the format only. Record unsupported or unavailable endpoints explicitly in the report; never substitute a fabricated result.

Required report sections: `Methods`, `Re-Discovery`, `New-Discovery`, `Results`, `Limitations`, `Clinical Safety`. Explain source cohort construction, methods, adjustments, uncertainty, data versions, deviations from the paper and one bounded extension.

For a GitHub submission, include:

- System name, model/version, agent scaffold/version and prompts/configuration.
- Benchmark commit, protocol, track and all attempted task IDs.
- Per-task score and run status; report failures and boundary cases.
- Runtime, hardware, token budget and cost where available.
- Source-data provenance and permitted access conditions.
- Code and participant-free output links, with environment/dependency instructions.
- Disclosure of access to benchmark targets, reference utilities or source-paper results.

Do not attach raw participant records, credentials, unauthorized restricted extracts or copyrighted full text. For credentialed tasks, describe how authorized reviewers can reproduce the analysis within the permitted environment.

For UKB/mixed tasks, disclose the declared source release, withdrawals status, execution profile and unmet contract requirements. Keep the prepared participant tables and their local manifests in the authorized environment. Report local results as development results; `ranking_score` is null in this release. The Neurology_000 diagnostic alone is not a full submission.

To earn uncertainty or sensitivity completion points under v3, include [structured analysis evidence](ANALYSIS_EVIDENCE.md) with result tables generated by your analysis. Mentioning an analysis in prose is insufficient.
